# Johnny

A browser workspace for Johnny's simplified decimal Von Neumann computer. Serve this directory with any static HTTP server. The simulator, example programs, and help run locally in the browser. RAM, microcode, and preferences are stored in browser storage.

The default and Bonsai instruction sequences and `.ram` and `.mc` formats are based on [Johnny 2.0 by TobisMa](https://github.com/TobisMa/johnny/tree/20c86d316a844fc0fef6483f8ade99d48de0b13e), which builds on [David Laubersheimer’s web port](https://github.com/laubersheini/johnny) of [Peter Dauscher’s original Johnny simulator](https://sourceforge.net/projects/johnnysimulator/).
