ONENOTE → OBSIDIAN TEST 0.1

Try the document API.

A small test for your shared notebook. Runs in OneNote on the web and hands a Markdown copy to Obsidian. No Entra app registration, API key or VPS.

The part we still need to test: whether your organization allows a custom OneNote add-in, and whether your iPad's OneNote web editor exposes it. This has not been verified with your account.

  1. Save the manifest to Files

    In Safari, download this XML file. If Safari displays XML instead, touch and hold the button, then choose Download Linked File. Keep the .xml extension.

    Download test manifest

    This is an Office add-in manifest. Its ID identifies this add-in locally; it is not a registered Entra OAuth application.

  2. Open your shared notebook in Safari

    Open OneNote on the web with your normal Microsoft sign-in. Open the shared notebook and a small page with typed text. Stay in Safari rather than opening the OneNote app.

    If the full editor does not appear, use Safari's page menu and choose Request Desktop Website.

  3. Upload the add-in

    Look for Home → Add-ins → More Settings → Upload My Add-in. Some OneNote layouts use Insert → Office Add-ins → My Add-ins / My Organization → Upload My Add-in.

    Choose OneNote-Obsidian-Test.xml from Files. If prompted, add OneNote to Obsidian Test.

    If Upload My Add-in is missing, disabled or denied: stop here and report the message or show the menu. This route depends on Office add-ins being allowed. It does not override your organization's policy.

  4. Read one page, then try Obsidian

    In the new pane, tap Read current page. A successful test shows your notebook, section, page title and a Markdown preview.

    Enter your exact Obsidian vault name and tap Open in Obsidian. The test creates a uniquely named note under OneNote Test. If the app link is blocked, use Copy Markdown or Save / share .md.

Scope and permissions

This first version reads the active page. It preserves text, basic formatting and simple table cells; images, handwriting and attachments are explicitly marked as omitted. OneNote's freeform layout and list indentation can change in Markdown.

The code does not change your OneNote page or run automatic synchronization. The manifest uses ReadWriteDocument because Microsoft requires that permission for OneNote-specific document APIs, including reads. There is no Graph permission or additional login flow in the code.

The bridge processes the page inside the pane. It does not upload notebook content, store credentials or save page content on this website. Export happens when you choose a handoff action.

Validated with automated tests and a simulated Office host. Real OneNote access, shared-notebook access and the iPad handoff still need this test in your account.

After the test

If the page read works, it proves this route can read that shared page through OneNote's own document API. It does not yet prove reliable background sync or safe two-way editing. A fuller bridge would need page navigation, change tracking and conflict handling. On iPad, this browser-based route needs an open OneNote session.

You can remove the add-in from My Add-ins afterwards. Test notes in Obsidian can be deleted independently.
