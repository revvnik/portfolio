What this test does

Uses OneNote's document API in the open web page. No Graph login, Entra registration, API key or VPS. Your existing OneNote sign-in stays with Microsoft.

The bridge converts the page in this pane and passes Markdown to Obsidian only when you tap an export action. It does not upload your note to this website or store its content.

It creates a uniquely named note in OneNote Test. It does not change the OneNote page. This is a manual access test, with no automatic sync or write-back yet.

Office requires the manifest permission ReadWriteDocument for OneNote's document APIs. This test's code only calls read methods.
